# Frequently Asked Questions

## Installation & Setup

### Q: What is MOOSE?

**A:** [MOOSE](https://mooseframework.inl.gov/) (Multiphysics Object Oriented Simulation Environment) is a finite element framework developed at Idaho National Laboratory. Redback is built as a MOOSE module.

### Q: How do I install MOOSE?

**A:** Follow the [MOOSE installation guide](https://mooseframework.inl.gov/getting_started/installation/index.html).

### Q: Where should I clone Redback?

**A:** Clone into `${MOOSE_DIR}/../redback` so it's a sibling to the MOOSE directory:

```bash
cd ${MOOSE_DIR}/..
git clone https://github.com/RedbackProject/redback.git
```

## Running Simulations

### Q: How do I run a simulation?

**A:** See the [Usage Guide](user-guide/usage.md). Basic syntax:

```bash
mpiexec -n 4 redback-opt -i input_file.i
```

### Q: How do I visualize results?

**A:** Use [Paraview](https://www.paraview.org/) or [VisIt](https://visit.llnl.gov/) to open `.e` (Exodus II) files generated by Redback.

### Q: What do the output files mean?

**A:** See the [Usage Guide - Output Files](user-guide/usage.md#output-files) section.

## Building Documentation

### Q: How do I build the documentation locally?

**A:** Install MkDocs and build locally:

```bash
pip install -r requirements-docs.txt
mkdocs serve
```

Then open `http://localhost:8000` in your browser.

## Troubleshooting

### Q: Compilation fails with "MOOSE_DIR not found"

**A:** Set the MOOSE_DIR environment variable:

```bash
export MOOSE_DIR=/path/to/moose
```

### Q: Tests are failing

**A:** Make sure:
1. MOOSE is properly installed
2. You're in the redback repository root
3. You have the right permissions

Run with verbose output:

```bash
./run_tests -v
```
