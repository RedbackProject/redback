# Redback Documentation

Welcome to the **Redback** documentation! Redback is a MOOSE module for rock mechanics with dissipative feedbacks.

## What is Redback?

Redback (Rock mEchanics with Dissipative feedBACKs) is a [MOOSE](https://mooseframework.inl.gov/) module designed to simulate rock mechanics problems with coupled processes.

## Key Features

- **Coupled Multiphysics**: Thermohydromechanical (THM) simulations
- **Rock Mechanics**: Specialized for geomechanics applications
- **MOOSE Integration**: Built on the powerful MOOSE framework
- **Flexible**: Extensible for custom physics and materials
